Endlessly streams videos based on a search term, rebuilt and modernized from the original 2012 Video Hackday project.

This fork updates the original concept with a modern video pipeline, fresh APIs, and a lightweight reactive front‑end while preserving the nonstop‑playlist behavior.

Original project home: http:// showmenonstop.com 
View Original source: `https://github.com/jamiew/showmenonstop` [(github.com in Bing)](https://www.bing.com/search?q="https%3A%2F%2Fgithub.com%2Fjamiew%2Fshowmenonstop")

Originally built with VHX and YouTube for NYC’s inaugural [Video Hackday](http://nyc.hackday.tv).  
This fork replaces deprecated APIs, adds a custom playlist engine, and introduces a modern UI.
